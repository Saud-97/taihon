## Why Taihon?

Taihon is an enhanced Mihon experience designed for users who want more.

It follows Mihon's development closely to keep the stability and features users rely on, while introducing additional improvements focused on speed, convenience, and flexibility.


## Planned Features

### ⚡ Speed
* Faster updates and downloads.
* Faster manga search.

### 📚 Library
* Better library update tracking and error handling.
* Filter your library for manga with unavailable or removed sources.

### 🔎 Search
* Open manga directly from supported source URLs.
* Show the latest chapter number and chapter counts in search results.

### 📖 Reading
* More control over scrolling, jump distance, and animation speed.

### ☁️ Sync & Backup
* Keep reading progress synced across devices using supported trackers.
* More flexible backup scheduling and retention options.

More improvements are planned over time.

## Core Features
</summary>

* Local reading of content.
* A configurable reader with multiple viewers, reading directions and other settings.
* Tracker support: [MangaBaka](https://mangabaka.org), [MyAnimeList](https://myanimelist.net/), [AniList](https://anilist.co/), [Kitsu](https://kitsu.app/), [MangaUpdates](https://mangaupdates.com), [Shikimori](https://shikimori.one), [Bangumi](https://bgm.tv/), and [Hikka](https://hikka.io/) support.
* Categories to organize your library.
* Light and dark themes.
* Schedule updating your library for new chapters.
* Create backups locally to read offline or to your desired cloud service.
